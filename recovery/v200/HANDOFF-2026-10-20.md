## 5. What worked, and what did not

**Worked:**
- **Small Codex batches with literal reports.** Each report pins its base by blob hash, so the lead can check it is the
  same tree (`git rev-parse <sha>:<path>`) before trusting anything.
- **Rebuilding a tiny fix rather than waiting for a diff.** F4 cost little; for D5, a three-board, two-manager scenario,
  pasting the diffs is far cheaper.
- **Focused runs of one suite block** (`recovery/v200/bin/focus-block.py`): about 30 s instead of 10–13 min for the
  whole suite. Prove "fails on the base, passes on the fix, each mutant caught" this way, then run the whole suite once.
- **Full gates run in the background, in sequence:** check → audit-recon → audit-import alone, with the lock. The
  20 Oct gate took 22 min in all.
- **The text-only mutation tools:**
  - `mcount.py <mutate.mjs> <board>` prints entries, once, missing, multiple, unparsed.
  - `mkmut.py <mutate.mjs> <board> <id> <out.html>` builds one mutant. Diff it against the board to see the single change.
- **Commits from a clean worktree** with an explicit identity and a no-hooks path:
  `git -c user.name=Claude -c user.email=noreply@anthropic.com -c core.hooksPath=<empty dir> commit`.
- **For PR-body edits,** a script that asserts each anchor matches exactly once before replacing it.

**Did not work, or cost time:**
- **Not checking the PR's state** before treating it as open (section 0). Before any push meant for a PR, run
  `pull_request_read get` and check `merged`.
- **AskUserQuestion with nothing in the background:** it blocked about 6 hours overnight on 18–19 Oct.
- **Agents left idle:** a U37 round-8 tests reviewer sat 6 h and was stopped.
- **Memory:**
  - Two heavy suites at once got audit-recon killed by signal 9 on 19 Oct. Run suites one at a time.
  - Codex's U44 block needs an 8 GB heap.
- **Timeouts:** for suites, use `timeout -k 10 <cap>`. audit-import takes about 11–13 min and audit-recon about 10 min.
- **Small breakages:**
  - `wfstate.py` read only rounds 1–6; it was widened to 1–8.
  - `git bundle` refuses a bare sha; make a named ref with `update-ref` first.
  - `pypdf` is broken; use `pdftotext`/`pdfinfo`.
  - A safety check blocks `rm` after `cd`; use absolute paths.
- **Inside the PDF generator:** landscape pages need the page size from `c._pagesize`, and bullets need `bulletFontName`.
- **Codex's environment:** no proxy to npm or git at first. Brad approved one bounded setup step (portable Node). Its
  logs use Windows paths, and one run added a final newline to the board, which Codex caught by blob hash.
